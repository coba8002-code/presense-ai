# G5 기록 돌아보기 — 2026-10-31

목적: 선택한 반려견의 최근 7/30일 상황 기록과 후속 관찰 누락을 한눈에 확인한다. 기존 글로벌 G5 설계와 계속 개발 지시에 따른 작은 기능 단위다.

계약: GET /v1/me/journal/summary?pet_id=<id>&days=7 또는 30. 서버 현재 시각까지의 연속 7/30×24시간이며 시작 포함/종료 포함이다. 미래 관찰은 제외한다. 만료되지 않은 선택 개체/소유자 기록 전체를 집계하며 50개 목록 페이지에 제한되지 않는다. 동일 이름은 합치지 않는다. 후속은 해당 기간 상황에 연결되고 현재까지 관찰된 기록만 센다. 삭제/만료는 즉시 반영한다. 새 보관이나 TTL 연장은 없다.

출력: 기간, 기록 수, 행동별 기록 수, 후속이 있는 상황 수, 후속 없는 상황 수, 후속 기록 수. 원문/소유자/토큰은 포함하지 않는다. 보호자 진술이고 모델 분석·학습 정답·행동 빈도·효과 증거가 아니다. 한국어/영어 표시, 프로필 변경과 로그아웃 시 초기화 및 늦은 응답 차단.

구현 순서: 실패 테스트 → store 집계/API → 기존 일지 화면 → 회귀 검사. 기존 FastAPI/SQLite/vanilla JS 사용, 추가 의존성/스키마 변경 없음. 코드 스타일은 기존 소유권 트랜잭션과 textContent 렌더링을 따른다.

검증: `python -m unittest discover -s tests -p 'test_journal*.py' -v`, `node tests/test_journal_ui.cjs`, `scripts/verify_release.py`. 기간 경계/미래/50개 초과/타 소유자/동명 개체/만료/철회/삭제/HTTP 경로를 확인한다. 실제 기기 및 고객 효용은 별도 검증한다.
