# PetSense AI 제품기획서
> 2026-10-28 · v5 · 개 전용 · 구현과 제안 구분

## 제품 약속
‘우리 개의 일상을 기록하고 변화와 상황을 설명할 수 있게 한다.’ 핵심은 관찰 기록의 연속성이다. 감정 번역·질병 확정·만능 교정법을 약속하지 않는다. 장기 대상은 전국 개 보호자이며 첫 검증 대상은 반복되는 짖음과 일상 변화를 기록하려는 가정이다.

## 현재 제공 흐름
/app에서 반려견 이름과 당시 상황 입력 → 지원 WAV 선택 → 분석 동의 → 로컬 서버 AST 사건 점수 → 원인·감정 판단 보류 → 사용자가 선택하면 브라우저에 저장 → 기록별 삭제/전체 삭제/JSON 내보내기.

이번 구현 범위: 반응형 웹 화면, 같은 서버의 /v1/audio/events 연결, 입력 오류와 서비스 준비 오류 안내, 명시적 저장, 100개 기록 상한, 파일 원본 미저장, 토큰 비저장. 개발용 서버 토큰은 연결 설정에 위치한다. 상용 버전에서는 계정 인증으로 대체한다.
이번 구현의 한계: 16kHz PCM16 WAV 0.1~10초/2MB 제한. 일반 스마트폰 영상·녹음 파일 자동 변환, 영상 분석, 클라우드 계정 동기화, 가족 초대, 결제, 앱스토어 배포는 미구현. 브라우저 저장은 백업이나 암호화 계정 저장이 아니며 사이트 데이터 삭제 시 소실된다.

## 전국 사용성 확장
초기에는 한국어·휴대폰 세로 화면·큰 버튼·텍스트 설명을 기본으로 한다. 이후 저사양 Android에서 촬영 구간만 업로드, 느린 네트워크 재시도, 큰 글자·스크린리더, 보호자가 여러 마리를 등록하는 흐름을 추가한다. 고양이는 현재 범위 밖이다. 지역·품종·나이·성별·털색·촬영 거리별 품질을 따로 보고한다. 품종별 성격을 고정적으로 단정하는 안내를 만들지 않는다.

고령 보호자는 첫 화면에서 파일 형식을 알아야 하는 부담이 크다. 상용 MVP 전 반드시 앱 녹음/영상 추출을 구현한다. 현재 WAV 제한은 개발 실험의 제약이며 대중 서비스 UX의 완료 기준을 충족하지 못한다.

## 학습과 근거 콘텐츠 정책
관찰(소리·자세), 보호자 진술, 전문가 해석을 별도 필드로 저장한다. 피드백은 자동 정답이 되지 않는다. 방송·보듬TV 자료는 권리자가 허락한 원본/자막과 출처 시간 구간을 갖춘 사례 카드 후보로 활용한다. 검수된 근거만 설명 검색에 사용한다. 인터넷 링크 발견, 검색 증강 설명, 모델 미세조정은 서로 다른 작업이다.

## 실험과 출시 조건
주요 지표는 ‘4주 동안 자발적으로 반복 기록한 가정 비율’이다. 첫 분석 완료, 저장, 재방문, 오류 해결, 상담 전달 유용성을 보조 지표로 둔다. 현재 앱에는 외부 분석 SDK가 없으며 운영 코호트 측정은 동의 설계 후 구현한다.
기술 지표 제안: 별도 개체/가정 평가에서 사건별 recall/precision·macro F1·오탐/시간·coverage·calibration·p95 지연 측정. 목표 수치는 클래스와 손실 비용을 정한 뒤 확정한다. 공개 자료의 점수를 그대로 출시 기준으로 사용하지 않는다.
출시 차단: 원본 권리 미확인, 인증·삭제 결함, 잡음을 개 소리로 빈번히 판정, 모델 미준비를 정상 성공으로 표시, 브라우저/기기 주요 흐름 실패. 현재는 제한된 로컬 개발 미리보기다.

## 제외 및 후속 의사결정
초기 소셜 피드, 쇼핑몰, 기기 자체 제작, 보험 판매, 상시 감시 카메라 기능은 우선순위가 낮다. 사용자 유지와 분석 신뢰도를 검증한 뒤 요청 빈도·수익성·운영 비용으로 판단한다. 확장 아이디어 수를 제품 성과로 삼지 않는다.

## 2차 개발 반영 — 입력과 기록 활용
구현: 마이크 최대10초 녹음, 사용자가 고른 음성 파일에서 시작 구간 선택, 브라우저 내 mono/16kHz PCM16 WAV 변환. 원본 파일20MB 제한, 동의 해제/취소/화면 이탈 시 마이크 해제. 선택 구간 표시와 최근7일(KST 날짜)의 기록 수·기록일 수, 상담 준비 텍스트 내보내기를 추가했다. 데이터는 브라우저의 최대100개 저장 기록 범위다. 같은 이름은 합산되므로 개체 ID를 갖춘 다견 계정 기능은 후속이다.
이는 통제된 관찰시간을 바탕으로 한 행동 추세 분석이 아니다. 센서 관찰 누락·노출시간이 없어 개선/악화를 판정하지 않는다. 원본은 자동 저장하지 않으며 다운로드 보고서는 사용자가 공유 여부를 결정한다.
검증: Python122개 테스트, Node 모의 DOM 및 WAV/변환/주간 집계 검사 통과. 마이크 permission 대기 중 취소·동의 철회·정상 종료 시 track 해제를 모의로 확인했다. 실제 브라우저의 Web Audio 렌더링과 모바일 코덱은 미검증이다. 마이크는 HTTPS/localhost에서만 지원되며 휴대폰에서 PC의 HTTP LAN 주소로 접속하는 경우 파일 선택을 사용하거나 별도 HTTPS 구성이 필요하다.
다음 우선순위는 국내 PC·실제 휴대폰 E2E, 운영 사용자 인증·계정별 기록 접근, 비동기 분석/오류 복구다. D03 음성 입력 부분은 구현됐고 영상 파일 처리 및 실기기 완료 조건은 남아 있다.
