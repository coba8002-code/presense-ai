# 서비스 GUI 시안

## 제공물과 범위
`/design`은 회원가입→반려견 등록→홈→분석 요청→처리 상태→결과/기록의6개 화면을 클릭하는 독립 HTML 프로토타입이다. `/app`의 실제 개발 기능과 분리했다. 이 시안은 계정 생성·결제·마이크·파일 읽기·서버 분석을 실행하지 않는다. 이메일/비밀번호는 읽기 전용 예시이며 개인정보를 입력받지 않는다. 반려견 이름/상황/기록은 화면 메모리에만 남고 새로고침하면 사라진다. CSP connect-src none, microphone/camera/geolocation 비활성화로 네트워크/기기 경계를 막는다.

서비스 서버를 실행한 뒤 `http://127.0.0.1:8000/design`에서 확인한다. `/app`은 실제 기능 개발 화면이며 운영자 발급 세션·모델/작업자 설정이 필요하다. GUI 시안의 회원가입 버튼으로 실제 계정이 만들어지지 않는다.

## 화면과 설계 의도
|화면|핵심 구성|실제 구현과의 관계|
|---|---|---|
|회원가입|필수 동의 분리·예시 이메일/비밀번호·시작|운영 가입/복구/API 연결은 미완료. 약관/정책 법률 검토도 별도|
|반려견 등록|개 전용·이름·프로필 보관 동의|실제 /app에는 소유권/프로필/30일 보관 API가 있음|
|홈|새 관찰·최근 기록·기록량/관찰 범위|기록 수를 짖음 빈도나 개선으로 표시하지 않음|
|분석 요청|녹음/파일 예시·최대10초·상황·분석/임시 보관 별도 동의|실제 /app에는 변환/녹음·직접/큐 API가 있음. 시안의 입력은 샘플 전환만 수행|
|처리 상태|접수·분석·결과·취소|가짜 확정 처리시간/진행률을 계산하지 않음. 시안의 예시 결과 버튼으로 이동|
|결과·기록|상위 사건 예시 점수·판단 보류·상황 메모·명시적 저장|실제 모델 정확도 증거가 아니며 시안 점수는 예시. 실제 /app 큐는 원본7라벨을 반환|

초록/청록·웜 아이보리, 원형 카드, 읽을 수 있는 대비, 큰 입력과 버튼을 공통 요소로 쓴다. 개인정보 수집은 현재 프로필의 이름부터 시작한다. 별도 생성한 디자인 보드는 방향 제안 이미지이며 HTML/실제 앱과 픽셀 단위 동일 화면이 아니다. 보드의 예시 기록/점수/진행률은 운영 데이터가 아니다.

## 검증과 다운로드
`scripts/design_browser_smoke.py --output-dir artifacts/gui-new`는 실제 Chromium에서 동의별 버튼 차단·화면 전환·HTML 문자 안전 표시·메모리 기록·새로고침 초기화·API0호출을 검사한다.390/1440폭에서 가로 넘침을 확인하고6개 화면/데스크톱 PNG를 저장한다. CI에는 한국어 스크린샷용 Noto CJK 폰트를 설치한다. 실제 iOS/Android·스크린리더·모든 글자 확대를 검증한 것은 아니다.
다운로드 패키지는 index.html과 design/design.css, design/design.js를 함께 담는다. 압축을 풀고 index.html을 열면 서버 없이 클릭 시연할 수 있다. ‘개발 앱 /app’ 링크는 프로젝트 서버에서만 동작한다. 이미지 보드와 사업성 평가 Markdown도 별도로 제공한다.
