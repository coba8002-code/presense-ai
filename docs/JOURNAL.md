# 반려견별 상황·후속 돌봄 일지

## 구현 계약
글로벌 개발 설계 G5의 첫 단계다. `/understand`의 보호자 상황을 문자열 메모와 별도로 구조화하고, 반려견별 목록·후속 관찰·명시적 내보내기/삭제로 연결한다. 보호자가 한 행동과 뒤에 관찰한 모습을 보존하며 원인·교정 효과·학습 정답으로 자동 판정하지 않는다. 새 외부 AI/유료 API·공개 공유는 추가하지 않는다.

기존 SQLite·HttpOnly 계정 쿠키/CSRF·개 소유권을 사용한다. 기존30일 메모와 과거 자료를 자동 변환하지 않는다. 상황 기록과 후속 기록은 각각 사용자 확인을 거친다. 보관 동의는 `journal-storage-v1`이며 상황 작성 시30일 또는90일을 선택한다. 선택한 개 프로필 이름/ID와 상황·후속 기록을 해당 상황의 등록 시각부터 보관한다.90일 선택은 선택한 프로필의 만료도 그 기한까지 연장하며, 기존 메모·음성/작업 결과의 보관 기간은 바꾸지 않는다. 후속 작성·조회·이름 수정으로 원래 상황의 만료를 늘리지 않는다.

## 데이터·권한·제한
상황: 개 ID, 관찰한 시각, 행동 코드, 직전/관찰/직후 각80자, 이어진 기간 구간, 보호자가 보는 평소 차이, 현장 개 수, 건강 우려 여부, 보관 선택. 후속: 시각, 보호자가 선택한 행동 분류·설명300자, 이후 관찰 분류·메모300자. UTC로 저장하고 기기의 IANA 시간대로 표시한다. 관찰 시각은 시간대가 있는 값만 받으며 현재부터90일 이내의 과거~5분 이내 미래만 허용한다. 후속 시각은 원래 관찰보다 빠를 수 없다.

클라이언트 owner·모델 판단·confidence·training 승인 필드는 거절한다. 응답은 guardian_report/model_analysis=false/training_approved=false를 명시한다. 권한 없는 개/상황은 없는 ID와 같은404. 계정당 상황500개, 상황당 후속20개, 목록50개씩 최대500개 조회. JSON4KB·업로드15초. 쓰기는 세션·소유권·동의·한도·멱등 키를 같은 트랜잭션에서 검사한다. 같은 계정/키/내용 재전송은 같은 행을 반환하고, 다른 내용은409다. 전송 결과가 불명확하면 자동 새 키 재전송 대신 목록 확인을 안내한다.

상황 삭제는 연결 후속을, 개 삭제/만료는 연결 상황/후속을, 회원 탈퇴는 해당 계정의 전체 상황/후속을 제거한다. 만료 정리는 기존 접근/worker 및 독립 정리 CLI가 수행한다. v4→v5 마이그레이션은 기존 계정·프로필·메모·작업을 보존한다. 실제 운영 DB 변경 전의 백업·복구 검토와 국내 PC 설치/백업 삭제는 별도다.

## API
|경로|계약|
|---|---|
|POST /v1/me/journal|상황 JSON, Idempotency-Key, X-Journal-Consent=journal-storage-v1|
|GET /v1/me/journal?pet_id=...&offset=0|내 상황50개, 전체 수/다음 offset; pet_id 선택|
|GET /v1/me/journal/{id}|내 상황과 연결 후속 최대20개|
|POST /v1/me/journal/{id}/followups|후속 JSON, 같은 명시적 동의/멱등 키; 원래 만료 유지|
|DELETE /v1/me/journal/{id}|X-Delete-Confirm=delete-case; 상황/후속 삭제|

## 작업 순서와 검증
1. 서버 계약·마이그레이션·소유권/멱등/동의/만료/삭제·후속 시각/한도 검사를 먼저 작성한다.
2. 저장소/API와 정리 연동을 구현하고 전체 회귀 검사를 수행한다.
3. 한국어/영어 상황 저장과 일지·후속·내보내기/삭제 화면을 연결한다. 초안/쿠키/기록을 localStorage에 저장하지 않는다. 입력/선택/세션이 바뀌면 늦게 온 응답을 표시하지 않는다.
4. 실제 HTTPS 가입→상황→재조회→후속→내보내기→삭제/탈퇴와390/1440폭을 Chromium에서 검증하고 PR로 제공한다.

가족 초대·전문가 접근·활동 추천 모델·커뮤니티·실제 행동 정확도는 별도 단계다. 일지 작성 수나 주관적인 ‘진정함’은 실제 행동 빈도/효과의 인과 증거가 아니다.

## 웹에서 사용
HTTPS 계정 베타에 로그인하고 /app에서 프로필을 준비한다. /understand의 상황 카드를 만든 뒤 프로필·관찰 시각·30일/90일·별도 보관 동의를 확인하고 ‘내 개 일지에 상황 보관’을 선택한다. 하단 일지의 상황을 선택해 후속 시각/행동/관찰을 적고 기존 만료일까지의 보관에 동의한다. JSON 내보내기는 선택 상황과 후속만 포함하며 클라이언트가 명시적으로 선택했을 때 실행한다. 페이지 초안은 메모리에만 남고 계정/개 선택이 바뀌면 이전 요청/표시를 초기화한다.

서버12개 추가 검사를 포함한217개 Python 검사가 통과했다. API PR #15의 backend/browser41095795047·41095801695 및 실제 AST41095794946이 성공했다. 신규 일지 화면의 HTTPS·두 언어·후속/내보내기·프로필 변경 중 지연 응답 차단·삭제는 후속 UI CI에서 검증한다. 기존 CI 성공을 신규 화면 검증으로 대신하지 않는다.
