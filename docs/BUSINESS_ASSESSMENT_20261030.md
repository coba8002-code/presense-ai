# PetSense AI 냉정 평가 — 제품 완성도와 사업성

2026-10-30 KST. 내부 의사결정용 평가다. 투자 가치·시장 규모·성공 확률을 검증한 보고서는 아니다. 근거는 실제 코드/CI/검증 기록이며 최신 외부 시장 조사나 고객 인터뷰를 새로 수행한 것은 아니다. 아래에서 확인 사실, 사용자 진술, 판단/제안, 수치 가정을 구분한다.

## 의사결정 요약
**판단: 조건부로 계속 개발할 수 있으나, 현재 상태로 전국 유료 서비스 출시나 대규모 고객 획득 투자를 정당화할 근거는 부족하다.** 현재는 작동하는 개발용 프로토타입이며 제한된 현장 실증에 들어가기 전 단계다. 서버 개발 속도와 코드 검증은 진전됐지만 실제 개체/가정 성능, 운영 계정/보관/복구, 반복 사용과 지불 의향의 증거가 부족하다.

추천 제품 정의: **반복되는 소리·행동 상황을 보호자가 기록하고, 필요할 때 전문가에게 경과를 전달하도록 돕는 관찰·상담 준비 도구.** ‘개의 언어 번역’, 감정/원인 확정, 자동 진단, 교정 효과 보장을 주요 구매 약속으로 삼지 않는다. 초기 대상은 모든 애견인보다 반복 관찰/상담 필요가 있는 보호자와 기록을 실제 업무에 쓰는 기관으로 좁히는 편이 합리적이다. 이는 시장 검증 전 전략 제안이며 성과가 아니다.

## AI 수준의 엄격한 해석
현재 실제로 확인한 모델 기능은 공개 AST의 개 관련 소리 사건 점수다. 개의 감정·요구·원인·교정 처방을 검증한 모델이 아니다. 독립 정답이 없어 실제 행동 해석의 정확도를 숫자로 제시할 수 없다.
공개 ESC-10 400개에서 AUROC/AP1.0을 확인했지만 dog40/기타360의 사건 순위 결과다. 개체·가정 ID와 사전학습 중복이 불명확하며 실제 집에서의 소음·다견·음악/해설·낑낑/하울링 품질을 대표하지 않는다. 이 수치를 광고의 ‘행동 분석 정확도100%’로 옮기면 안 된다. SmolVLM의 합성 optimizer/save/reload도 실제 개 자세 학습의 증거가 아니다.
YouTube 조사 코드는12검색 대상·24검색어·6배치와 사례 후보 처리까지 구현했다. 실제 공개 검색은403이고 키/브라우저가 미연결이므로 신규 영상 분석/추가 학습은0건이다. 인터넷 자료가 많다는 사실은 원본 권리·동기화·개체 ID·검수 품질·독립 평가의 해결을 보장하지 않는다. 모델끼리의 일치나 방송 해설도 독립 정답이 아니다.

## 사업 기회와 가장 큰 실패 가능성
**기회에 대한 판단:** 보호자는 상황을 기억/설명하기 어렵고 기관은 상담 전후 정보를 정리하는 비용을 부담할 수 있다. 소리 구간·당시 상황·기간별 기록·불확실성을 묶어 전달하는 흐름은 검증할 가치가 있다. 국내 언어/상담 업무 적합성·동의된 개별 기록·파트너 도입 경험이 쌓이면 방어력이 생길 수 있다. 현재 지불 의향과 업무 절감은 가설이다.

|위험|현재 평가|반증/완화에 필요한 증거|
|---|---|---|

경쟁 비교는 현재 직접 실험하지 않았다. 범용 AI나 기존 반려동물 서비스에 특정 기능이 없다고 단정하지 않는다. 현재 가장 큰 미검증은 ‘모델을 더 붙일 수 있는가’보다 고객이 이 결과를 신뢰하고 반복 사용/구매할 충분한 이유가 있는가다.

## 추천 수익 모델 순서
1. 제한된 기관·보호자 실증에서 상담 전 기록/경과 정리의 유용성을 확인한다. 초기에는 사람의 상담을 대체하지 않는다.
2. 기관용 기록·과제/경과 관리와 보호자용 보관/상담 리포트의 지불자를 각각 확인한다. 기관 구매와 보호자 동의를 한쪽 성공으로 동시에 가정하지 않는다.
3. 반복 사용과 비용이 맞을 때 한도형 보호자 구독 또는 기관 구독을 실험한다. 무제한 고비용 분석은 원가가 확인되기 전 제공하지 않는다.
4. 상담 중개·상품 제휴·기기·보험 등은 법률/계약·이해상충·운영 부담을 별도 검토한 뒤 결정한다. 초기 수익의 확정 전제로 넣지 않는다. 원본 데이터 판매를 기본 모델로 삼지 않는다.

## 손익을 보는 방법 — 기존 계획의 숫자는 가정
기존 사업계획의 월11,000원(VAT포함) 시나리오는 공급가10,000원, 환불2% 반영 순매출9,800원, 결제330원+추론1,000원+저장200원+지원600원=변동비2,130원, 기여이익7,670원이다. 월 고정비1,200만원 가정에서 손익분기는1,565명이다. 추론비가3,000원이면 기여이익5,670원, 손익분기2,117명으로 바뀐다. 산술은 맞지만 실제 가격 수용/원가/유료자 확보의 증거가 아니다.
해당 시나리오는 무료 사용자 비용, 실제 검수·기관 교육/영업, 운영 대응, 기기/전력/백업, 앱 유통 수수료와 재처리 부담을 실제 구조에 맞춰 보정해야 한다. 개별 사용자 리포트마다 전문가 검수가 필요해지면 그 직접비를 따로 계산한다. 초기 데이터셋 검수 R&D비와 매 요청 검수비를 이중 계산하지 않는다.

기여이익 = VAT제외·환불 반영 순매출 − 결제/유통 수수료 − 유료/무료 분석에 배부한 추론·보관·검수·지원 직접비.
손익분기 유료자 = 월 고정비 ÷ 유료자당 기여이익(양수일 때 올림).
CAC 회수기간 = 실제 신규 유료 획득비 ÷ 해당 코호트의 월 기여이익.
실제 유지/이탈이 없으므로 LTV나 사업 성공 확률을 확정하지 않는다. 전체 반려인 수를 유료 고객 수로 바꾸거나 최신 공식 분모 없는 TAM/성장률을 새로 제시하지 않는다.

## 완성까지의 우선순위와 외부 의존
바로 개발 가능한 기반은 프로필·소유권·큐·GUI로 진전시켰다. 다음 순서는 운영 인증/복구/권한 설계, 실제 데이터 스키마/독립 평가 연결, 실제 기기, 보관/정리·백업/장애·원가 검증이다. 개인정보/권리/사용량 조건은 실제 운영 설정과 검토가 필요하다.
