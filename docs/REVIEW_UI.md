# 개 영상 검수 화면

`python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000` 실행 후 `http://127.0.0.1:8000/review`를 연다. 이 화면은 로컬 파일 기반 검수 작업 공간이며 서버 계정·전문가 자격 인증이나 공동 작업 저장소가 아니다.

## 사용 순서

1. [VLM 검수 CLI](VLM_TRAINING_TODO.md)로 현재 유효한 후보를 `data/video-proposals.json`에 내보낸다.
2. 화면에서 후보 JSON을 연다. 개의 직접 관찰만 받으며, 가설·발언·고양이·잘못된 시간 범위·중복 ID는 거부한다.
3. 목록에서 관찰을 선택하고 해당 원본의 허가된 로컬 영상 파일을 연다. 영상은 서버로 전송하지 않는다.
4. 잘라낸 파일이면 원본 기준 시작 위치를 초로 입력한다. 구간 재생 버튼으로 관찰 내용을 확인한다. 영상 소스가 바뀌면 이전 영상 선택은 해제된다.
5. 행동 라벨, 전역 동물 ID, 촬영 세션, 승인된 데이터셋 이름, 분할, 검수자와 근거를 입력한다. 원본·로컬 영상·행동을 확인한 뒤 승인한다. 잘못된 관찰은 승인하지 않는다.
6. 승인한 항목을 `video-reviews.json`으로 다운로드한다. 수정한 입력은 승인 버튼으로 반영해야 내보낼 수 있다. 승인 취소 후에는 변경한 파일을 다시 내보낸다.
7. CLI로 현재 권한과 분할을 재검증한다. 화면은 학습 가능 여부를 확정하지 않는다.

```bash
python -m training.video_review --db data/knowledge.sqlite3 \
  --config config/knowledge.local.json --reviews data/video-reviews.json \
  --registry datasets/registry.json > data/video-annotations.json
```

이후 [로컬 영상 검증](VIDEO_MEDIA.md)에 별도 bindings.json을 제공한다. 화면의 영상 선택·오프셋은 재생을 위한 것이며 파일 해시 또는 binding 검증을 대신하지 않는다. GUI는 bindings.json을 생성하지 않는다.

## 현재 범위

- 파일 크기: 후보 JSON 8 MB 이하, 영상 128 MiB 이하. 브라우저 지원 코덱의 파일을 사용한다.
- 파일은 브라우저 메모리에만 존재한다. 자동 저장·검수 파일 다시 불러오기·로그인·서명된 감사 기록은 아직 없다. 페이지를 닫거나 초기화하기 전에 다운로드 파일을 확인한다.
- 목록 이동 시 승인하지 않은 입력 변경을 버릴지 확인한다. 새 후보 파일이나 초기화로 현재 작업을 비우기 전에도 확인한다.
- 모델 관찰은 HTML로 해석하지 않고 텍스트로만 표시한다. 네트워크 연결은 CSP로 차단하며 원본 링크는 사용자가 클릭할 때만 새 탭에서 연다.
- 후보 ID와 현재 DB의 일치, 이용 권한, 전문가 검수 기록의 진위는 화면 자체가 보증하지 않는다. CLI에서 현재 후보·권한·개체/세션/영상 분리를 다시 검사한다.
- 원본 주석 구간을 화면에서 수정하지 않는다. 잘못된 구간은 원본 주석을 수정하고 후보 ID를 다시 생성해야 한다.
- 초 단위 구간 재생은 브라우저 이벤트에 따른 대략적 멈춤이다. 정확한 프레임 매핑 및 재인코딩된 유사 영상 탐지는 후속 작업이다.

GitHub CI는 실제 Chromium에서 합성 WebM 재생, 범위 초과 차단, 승인/취소, 다운로드 JSON과 Python Review 스키마 호환, 입력 중인 수정의 내보내기 차단, 외부 요청·업로드 부재를 검증한다. 실제 개 영상과 모델 정확도를 검증한 결과는 아니다.
