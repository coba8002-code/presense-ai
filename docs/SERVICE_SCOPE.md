# PetSense AI 서비스 소개와 작업 범위

기준일: 2026-10-19 KST. 개 전용 연구·개발 프로토타입.

## 서비스 소개

개의 소리와 짧은 영상을 분석해 관찰된 행동을 정리하고, 검수된 행동학 자료와
전문가 사례를 근거로 보호자가 상황을 이해하도록 돕는 서비스다. 관찰과 해석,
불확실성을 구분한다. 언어 번역·질병 진단·교정 성공을 보장하지 않는다.

## 작업 범위

| 작업 | 상태 | 산출물 / 완료 기준 |
|---|---|---|
| WP1 음향 모델 연결 | AST CLI·실제 가중치 CI 성공. Dog2vec/AVES 보류 | 고정 모델 버전·조건·원본 라벨, 파일 추론·오류 처리 검증 |
| WP2 실제 데이터 평가 | 미완료 | 권리/검수 manifest, 개체·가정·세션 분리, 기본 모델 평가 보고서 |
| WP3 영상·멀티모달 | 정지 자세 합성 LoRA 검증, 실제 평가 미완료 | 영상/음성/결합의 독립 평가와 실패 분석 |
| WP4 전문가 근거 검색 | 검색·검수 기반 일부 구현 | 출처·시간·관찰·해석·개입·결과 카드, 승인/철회와 근거 추적 |
| WP5 앱·운영 | 미완료 | 인증·비공개 업로드·작업 처리·비용 한도·삭제·Flutter 실제 기기 흐름 |

112개 로컬 테스트, 음향 CI 39213061875, 백엔드·브라우저 CI 39213065678 성공.
테스트 통과는 개 인식 정확도를 뜻하지 않는다. 실제 개 데이터 학습·성능 비교와
출시 준비는 별도 과제다. 자세한 입력과 출력 제한은 PRETRAINED_DOG_AUDIO.md 참조.

## 진행 순서

1. 실제 개 데이터 권한·라벨·평가 계약 확보.
2. AST 기준 성능 평가, Dog2vec/AVES 가중치 조건 확정 후 비교.
3. 실제 자세 튜닝, 영상·음성 결합 및 시간적 행동 평가.
4. 강형욱 출연 공식 영상 등 사례 후보의 권한/내용 검수와 검색 설명 연결.
5. 앱·운영 기능 구현 후 제한된 사용자 검증.

## 제외 및 인수 조건

고양이, 감정 번역, 임상 진단, 상시 서버 전송, 다중 동물 추적은 초기 범위에서 제외.
모델 정확도·오탐·보류·보정과 지연/비용, 개인정보 삭제/동의, 실제 기기 전체 흐름,
모델 버전 회귀·롤백을 검증해야 출시 준비 완료로 판단한다. 일정·예산은 인력·데이터·
사용량이 정해진 뒤 산정한다. 현재 문서의 목표 수치는 달성 성과가 아니다.

## PDF 산출물 재생성

`scripts/build_service_pdfs.py`는 서비스 브로셔 2쪽과 상세 기획서 7쪽을
`artifacts/documents/`에 생성한다. 문서 도구 의존성은 PyMuPDF, fonttools와 시스템
Noto CJK 폰트이며 서버 런타임 의존성과 분리한다. 한글 폰트를 포함하고 폰트 라이선스를
PDF에 첨부한다. 상세 내용은 생성 스크립트에 보존한다.

- PetSense_AI_Brochure.pdf: 서비스 가치, 사용 흐름, 현재 성과와 한계.
- PetSense_AI_Project_Proposal.pdf: 목적·현황·MVP·작업 패키지·데이터·아키텍처·검증·진행 순서.
