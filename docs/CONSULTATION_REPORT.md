# 상담 준비 리포트 · 2026-10-31

기존 G5/G6 설계의 상담 준비를 구현한다. 보호자가 선택한 개의 최근 7/30/90일 기록을 시간순으로 정리하고 미기록 항목·후속 관찰 질문을 보여준다. 자동 진단, 감정 번역, 교정 효과 평가, 전문가 검수 완료로 표시하지 않는다.

GET /v1/me/journal/report?pet_id=...&days=7. 소유자만 사용하며 viewer 공유 권한은 보고서 API를 열지 않는다. 단일 SQLite 트랜잭션에서 세션/개체/만료를 검사하고 생성 시각까지의 기록을 취합한다. 미래 시각/만료/삭제는 제외. 최근 상황 최대100개, 각 후속 최대20개이며 전체 건수와 포함 건수·생략 여부를 명시한다. 100개 이상이면 기간을 줄여 다시 작성하도록 안내한다. 후속은 포함 상황에 연결된 현재까지의 기록이며 기간 뒤에 입력했더라도 관찰 시각이 현재 이하여야 한다. 추가 보관·TTL 연장·원문/모델 호출 없음.

화면: 한국어/영어, 7/30/90일 선택, 미리보기, 별도 기기 저장 동의 후 HTML 다운로드. HTML은 외부 요청/스크립트/원문 HTML 실행 없이 인쇄 가능하다. 프로필/기간/세션/페이지 변경 시 미리보기와 동의 초기화, 늦은 응답 차단. 다운로드 직전 최신 보고서를 다시 받아 삭제/탈퇴·기한을 반영한다. 이미 내려받은 사본은 서버 삭제로 회수되지 않는다.

구성: 반려견/기간/표시 시간대/생성 시각 → 기록 수·미기록 항목 → 날짜별 상황/후속 → 상담 질문 및 다음 관찰 체크리스트. 체크리스트는 확인할 항목 제안이며 일정/완료 상태가 서버에 저장되는 돌봄 계획 기능은 후속이다. 빈 기록도 명확히 표시한다. 건강 우려 미체크를 건강함으로 해석하지 않는다.

구현: backend/consultation_report.py의 집계, journal 라우트, report-core.js의 순수 문서 생성, report.js의 요청/미리보기/내보내기. 기존 vanilla JS/FastAPI/SQLite 및 테스트 사용, 추가 의존성/스키마 변경 없음.

검증: 기간 경계/최근100개/소유권/동명 개체/미래 후속/삭제·만료/세션 철회/TTL 불변/API no-store. Node에서 한영 패리티·주입 이스케이프·빈 자료·관찰 항목 표시. HTTPS 브라우저에서 두 언어 미리보기·실제 다운로드·기간/프로필 초기화. `python -m unittest discover -s tests -p test_consultation_report.py -v`, `node tests/test_consultation_report.cjs`, 전체 release 검사. 실제 상담 효용은 현장 검증 대상으로 남긴다.
