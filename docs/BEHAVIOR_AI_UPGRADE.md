# PetSense 관찰·음향·해석 고도화 계획

작성: 2026-11-01 KST. 범위: 개 전용. 목표는 보호자의 판단을 돕는 검증 가능한 관찰과 맥락 설명이다. 감정·의도를 번역하거나 의료 진단을 제공한다고 주장하지 않는다.

## 현황과 이번 구현

실행 코드 기반은 PR23 e34f61b이다. AST 7개 AudioSet 개 이벤트 점수와 단일 이미지 VLM 관찰이 존재한다. 실제 행동 정확도, 회사 VLM 실연동, AI-Hub 원본 검증은 완료되지 않았다.

이번 추가:
- AST 결과에 RMS dBFS·클리핑 비율·무음/클리핑 경고를 추가한다. 모델 점수와 최종 유보 정책은 변경하지 않는다. 임곗값은 공학적 초기값이며 평가로 조정해야 한다. 낮은 음량은 멀리 있는 실제 개 소리일 수도 있어 자동 삭제하지 않는다.
- `backend/behavior_evidence.py`: 최대30초/30개 시간순 프레임의 관찰 기록, 자세 집계, 동일 개체 확인 및 가시성/유보/신뢰도 필터. 프레임은 호출자가 제공하며 실제 영상 디코딩·추적은 하지 않는다.
- 반복된 웅크림·뒤로 향한 귀·말린 꼬리의 조합만 회피 가능성 후보로 제시한다. 프레임 시간·관찰 단서·대안·다음 관찰 질문을 함께 반환한다. VLM이 생성한 가설 문구 자체를 근거로 사용하지 않는다. 감정·의도는 null이며 규칙은 검증되지 않았다.
- 오프라인 실행: `python -m scripts.behavior_evidence --input observations.json --output evidence.json`. 입력은 `same_dog_confirmed` bool과 `frames` 배열이며 각 항목은 `seconds`, 기존 VisionResult 형식의 `observation`이다. 원본 미디어·계정 정보는 받지 않는다. API/UI 자동 연결은 후속 단계다.

## 데이터와 정답 설계

짖음/낑낑/하울링/으르렁은 음향 이벤트다. 불안·즐거움·통증·요구는 별도 가설이며 동일 소리에서 확정하지 않는다. 정답은 관찰 가능한 사건(접근/후퇴, 자극, 지속시간, 발성)과 평가자의 해석을 구분한다. 독립 평가자 2명 이상 및 불일치 조정, 판단 불가 표기를 사용한다. 전문가가 모든 자료를 직접 라벨링할 필요는 없지만 고위험 해석과 독립 평가셋은 자격·경력 확인된 검토자가 검수한다.

영상·연속 프레임·같은 개·가정·방송 회차가 학습/평가 양쪽에 섞이지 않게 한다. 보호자 후속 보고는 유용한 약한 신호이지만 감정 정답으로 취급하지 않는다. 방송/YouTube는 이용 조건·권리·편집 맥락을 검토한 검색 근거 후보이며 자동 수집/학습은 실행하지 않는다.

## 비교 후보와 적용 판단

아래는 조사/벤치마크 후보이지 설치·성능 확인 완료 목록이 아니다. revision, 코드/가중치/데이터별 라이선스와 국내 상업 서비스 이용 조건을 각각 확인한다.
- 음향: 기존 AST 기준선, https://github.com/microsoft/BEATs 및 https://github.com/LAION-AI/CLAP 비교. CLAP 텍스트 유사도는 행동 정답 확률로 사용하지 않는다.
- 자세: https://github.com/AlexTheBad/AP-10K 및 https://github.com/open-mmlab/mmpose 검토. 관절 위치 추정 성적과 행동 해석 성적을 분리한다.
- VLM: 기존 SMALL_VLM_TUNING 계획과 회사 모델을 먼저 비교한다. 크기·정확도·지연·메모리·상업 라이선스 확인 후 후보를 고정한다. 멀티이미지 입력만으로 동작 인식을 입증하지 않는다.
- 교정 지식: 출처/발행일/검토자/개정 이력과 함께 검색 기반 설명을 제공한다. 자극을 반복하거나 위험 행동을 재현하도록 유도하지 않는다.

## 측정·승격

음향: 클래스별 PR-AUC/F1·비개 소리 오탐·미탐·event onset/offset 오차. 영상: 자세/동작별 F1·가시성·동일개체 오류·유보율. 결합: 음성 단독/영상 단독/결합의 같은 테스트 표본 비교, 시간 정렬 오류와 누락 채널 평가. 설명: 근거 없는 주장률·관찰/가설 혼동·전문가 일치도. 모든 지표에 표본수·개체수·가정수·클러스터 신뢰구간을 기록한다.

임곗값은 validation에서만 선택하고 test는 잠근다. 실제 목표치는 기준선과 표본수를 확보한 뒤 정하며 90% 같은 숫자를 먼저 약속하지 않는다. 유보율을 낮추려고 위험한 확신을 늘리지 않는다. 실제 PC의 p50/p95 지연·RAM/VRAM·취소·재시작과 실기기 검사를 함께 통과해야 제품에 승격한다.

## 외부 의존성

회사 모델의 승인된 API/모델명/이미지 능력과 필요시 전용 인증, 국내 PC 데이터 검수 결과, 실제 개 관찰 정답이 필요하다. AX 계정은 선행 조건이 아니다. 이번 작업은 유료 호출·모델 학습·외부 전송·운영 배포를 실행하지 않는다.


## 제품 화면 연결 · 2026-11-01

`/app`의 “영상 장면 살펴보기”에서 `/video-review`로 이동한다. 이 화면은 AI 모델 미연결·보호자 직접 관찰임을 항상 표시한다. MP4/WebM 최대25MB·0.5~30초·1920×1080 한도이며 브라우저에서 최대6개 장면을 원본 영상 시각에 맞춰 추출한다. 이미지당 최대640px로 축소한다. 원본 타임라인 시각이지 음성과 영상의 자동 정렬이나 정확한 프레임 PTS 검증이 아니다.

영상과 관찰은 메모리에만 남는다. 네트워크 요청/저장 API가 없고 CSP connect-src none으로 전송을 차단한다. 모델·마이크·외부 URL·서버 전송 설정이 없다. 명시적 로컬 처리 동의와 같은 개 확인이 필요하다. 어느 확인이든 철회, 취소, 파일 교체, 페이지 이탈 시 URL·영상·프레임·결과를 폐기한다. 추출 중 오류/타임아웃에는 부분 프레임도 폐기한다. 미리보기 캡처에는 실제 고객 자료를 쓰지 않는다.

보호자가 가시성/자세/귀/꼬리를 각 장면에 직접 입력하면 출처가 보호자임을 표시한 규칙 후보를 확인할 수 있다. 미입력/상충 단서는 유보하며 감정·의도·행동 원인은 확정하지 않는다. 서버 VLM 출력과 보호자 입력을 혼동하지 않도록 이 화면은 계정 서버에 저장하지 않는다. 기존 오프라인 도구와 같은 제한된 단서 규칙을 사용하며 양쪽 모두 독립 검증 전이다. 프레임 사이 움직임·소리는 분석하지 않는다. 실제 VLM 호출·추적·동기화·계정 보관 연결은 여전히 후속 단계다.

검증: scripts.video_browser_smoke가 실제 합성 WebM으로 동의·동일개체 확인·6개 장면·직접관찰·상충·철회·취소·디코딩 실패·외부 요청 없음·모바일 화면 흐름을 확인한다. 실기기/실제 동물/모델 정확도 증거가 아니다. 음향 격리 환경에서 발견된 웹 의존성 오류는 training/audio_quality.py로 분리해 수정하고 재발 방지 검사를 추가했다.
