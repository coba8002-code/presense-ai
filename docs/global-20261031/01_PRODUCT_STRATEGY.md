# PetSense AI 글로벌 제품 전략

작성 기준:2026-10-31 한국 시간. 사용자 목표는 전 세계 보호자가 가장 많이 이용하는 반려견 서비스다. 이는 방향이며 현재 순위·점유율·성과가 아니다. 확인 사실/제안/검증 목표를 구분한다.

## 제품 정의와 선택 이유
**내 개의 소리·행동·생활 기록을 함께 살펴, 더 잘 이해하고 돌보며 함께 즐길 방법을 찾는 개인 돌봄 동반자.** 처음에는 낯선 짖음·혼자 있을 때 행동·산책 중 반응처럼 보호자가 구체적으로 궁금해하는 순간을 해결한다. 반복 사용할 이유는 내 개의 전후 맥락과 평소 변화가 쌓이고, 가족과 같은 기록을 보며, 해볼 활동과 상담 준비가 쉬워지기 때문이다.

‘왜 이러는지’, ‘무엇을 원하는지’에 답하려면 단순 사건 탐지에서 출발해 상황과 반복 기록을 확인해야 한다. 결과는 관찰 근거, 가능한 설명, 다른 설명, 더 확인할 질문, 안전한 다음 행동을 함께 제공한다. 근거가 모자라면 질문하거나 판단을 보류한다. ‘배고파요’ 같은 사람 말의 확정 번역이나 검증되지 않은 감정 확률은 핵심 효용으로 광고하지 않는다.

세계1위를 위한 차별화 **가설**은 ‘관찰→맥락 확인→개별 변화→작은 돌봄 행동→후속 기록→사람 연결’의 연결성이다. 각 기능이 경쟁사에 없다는 뜻은 아니며, 사용자가 더 유용하다고 평가하고 계속 이용하는지 비교 실증해야 한다. 스마트폰으로 먼저 시작하고 웨어러블 구매를 기본 진입 조건으로 만들지 않는다.

## 공식 자료에서 배운 점
세부 근거와 확인 한계는 [조사 기록](02_COMPETITIVE_RESEARCH.md)에 있다. 경쟁사 화면·영상·학습 자료를 복제하거나 제휴/연동이 성사됐다고 가정하지 않는다.

|참고 서비스|공식 자료의 기능|PetSense에 적용할 제품 원리|
|---|---|---|
|Dogo / Puppr|맞춤 훈련·강의, 트레이너 피드백/상담|분석에서 끝나지 않고 짧은 실천·확인·사람 피드백으로 연결|
|Tractive / FitBark|활동·수면과 평소 대비 변화, 전용 기기|개별 기준과 데이터 충분성 표시; 스마트폰 기록과 센서 관측량을 구분|
|Petcube|카메라의 짖음·대상 알림|무슨 사건인지와 왜 그런지를 분리; 향후 기기 API 검토|
|DogLog|가족/돌봄자 공동 기록·알림·추세|가족이 같은 상황을 보고 돌봄 중복을 줄이는 권한 기반 일지|
|DogPack|반려견 동반 장소·커뮤니티/외출|관계 형성·함께 즐길 활동을 관찰·돌봄 경험과 연결|

판매사 설명은 기능 확인 자료이며 효과·정확도·현재 활성 사용자 수를 독립 검증한 자료가 아니다. 가격·다운로드·매출 추정을 이 문서에 실적으로 넣지 않는다.

## 누구의 어떤 순간부터 해결할까
1차 검증 대상은 처음 개를 키우는 보호자와, 반복 행동의 맥락을 기록하고 싶은 가정이다. 전문 상담이 필요한 사례는 상담 준비·연결의 가치부터 검증한다. 위험한 행동을 재현시켜 영상을 만들거나 앱의 답 때문에 진료/전문 상담을 늦추게 해서는 안 된다.

홈의 첫 질문은 ‘오늘 우리 개에게 무엇이 있었나요?’다. 궁금한 순간을 기록하면 ‘보이는 것/들리는 것’, ‘직전·직후 상황’, ‘평소와 다른 점’을 순서대로 정리한다. 처음부터 긴 프로필/품종 입력·영상 업로드·구독 결제를 강요하지 않는다. 음성/영상 없이도 보호자 기록과 학습할 관찰 질문을 제공한다.

|영역|대표 기능과 사용자 가치|우선순위·완료 조건|
|---|---|---|
|이해하기|소리/영상/상황을 묶은 근거 카드, 확인 질문, 불확실성|P0: 상황 기록+기존 음성 사건 점수. 원인/의도 모델은 독립 평가 통과 후|
|우리 개 일지|반려견별 생활·행동 기록, 동일 관찰 조건의 추세|P0~P1: 실제 계정 일지·내보내기·삭제, 보관 정책 재설계|
|함께 돌보기|가족·시터의 초대/철회, 역할·활동 이력|P1: 계정 소유·초대 수락·최소 권한/재공유 차단 검증|
|함께 즐기기|짧은 냄새 놀이·산책/관찰 미션, 개별 적합성 확인|P1: 검토된 활동과 중단 조건, 강제 연속 참여/불안 유발 알림 배제|
|전문가와 연결|공유 범위를 선택한 상담 패킷, 피드백·후속 기록|P1: 지역별 자격/역할 표시·기한/철회, 실제 파트너 실증|
|커뮤니티|상황·생애 단계별 질문, 경험/전문 답변 구분·번역|P2: 신고·차단·운영자 대응·출처·위험 조언 처리부터|
|지역 생활|동반 장소·소모임·여행·실종 도움|P2~P3: 지역 데이터 권리·검수·위치 최소 공개; 제휴 검증 후|
|기기 연결|웨어러블/홈카메라 기록 연동|P3: 공급자 허가/API·동기화·개체 귀속 검증 후|

현재 구현: 개 전용 음성 사건 점수·프로필/메모·별도 큐, 실제 베타 계정 API와 웹 연결, 한국어/영어 상황 카드를 합성 브라우저 시나리오로 검증했다. 시안·합성 실행을 실제 행동 정확도나 글로벌 서비스 출시로 부르지 않는다. 가족/커뮤니티/전문가 네트워크/기기 제휴는 계획이다.

## 정확도가 제품의 신뢰가 되는 방식
음향 사건, 관찰 가능한 행동, 상황 설명, 의도 가설, 건강/위험 판단은 서로 다른 과제다. 하나의 ‘행동 정확도95%’로 합치지 않는다. [개발 설계](03_ARCHITECTURE_AND_DELIVERY.md)의 개체·가정·지역 분리 평가와 오류/보류 기준을 기능별로 통과시킨다. 기록 입력을 늘렸다는 이유로 정확도가 자동 상승했다고 표시하지 않는다.

제품 화면에는 근거 시각/구간, 보호자 진술 여부, 모델/자료 버전, 관찰 부족, 다른 설명, 다음 확인 질문을 표시한다. 수치가 보정되지 않았으면 확률로 해석하게 만들지 않는다. 다견·TV 음성·음악·편집 영상·품종/귀·꼬리 형태 차이·저조도는 별도 실패군이다.

## 커뮤니티를 유익하게 만드는 설계
내 개의 비공개 일지가 기본이고 공개 사례는 매번 별도 선택한다. 상담 영상·사람 얼굴/음성·주소·위치·주변 개를 자동 공개하지 않는다. 실제 사용자 정보가 공개되는 국가별 데이터 전송·삭제 방식을 검토한다. 공개 글을 자동으로 학습 허락으로 해석하지 않는다.

초기 커뮤니티는 ‘이런 상황에서 무엇을 관찰했나요?’의 맥락 템플릿과 경험 공유부터 시작한다. 전문가 자격 확인·광고/이해관계·AI 번역 여부를 표시하고, 도움 되는 답변 저장·해결/미해결 후속 기록을 제공한다. 좋아요 수를 의학/행동학 정답 순위로 사용하지 않는다. 학대성 교정법·의약품 지시·진료 회피·사기/차별/괴롭힘은 사람 운영과 신고 절차가 필요하다. 공개 피드보다 소규모 운영 가능한 주제 그룹을 먼저 검증한다.

## 세계 진출 순서와 성장
한국에서 검증하되 기술 구조는 언어·지역·시간대·통화·동의 버전을 분리한다. 영어권 소규모 공동 설계 집단을 병행해 한국 특유 UI/설명을 보편 기준으로 굳히지 않는다. 한국어/영어 핵심 흐름을 먼저 제공하고 일본어·스페인어 등은 고객 수요·현지 검수/지원 준비에 따라 결정한다. 언어 지원과 해당 국가 운영 허용·지원 가능은 별개다.

성장은 보호자가 직접 저장한 이해 카드·상담 요약의 선택적 공유, 가족 초대, 검증된 훈련사·보호소·입양 초기 돌봄 패키지에서 시작한다. 무차별 초대·연락처 수집·민감 사례 바이럴 대신 실제 도움을 재방문 이유로 만든다. 기관 채널도 기관의 업무 절감과 보호자의 효용을 각각 측정한다.

## 수익과 측정
제안: 기본 기록·내보내기/삭제·안전 안내는 접근성을 유지하고, 검증 후 고급 추세/리포트·분석 한도·가족 돌봄 편의의 구독을 실험한다. 전문가 상담은 실제 제공자·지역 자격·정산/환불이 준비된 유료 서비스로 구분한다. 기관 대시보드/입양 후 돌봄은 B2B2C 후보, 장소/제품 제휴는 이해관계 공개가 가능한 후순위다. 건강 불안을 이용한 구독 압박·개인기록 판매·분석 결과에 광고를 숨기는 방식은 채택하지 않는다.

현재 글로벌 수요·지불 의사·유지율·수익은 확인되지 않았다. 가격은 국가별 세금/환율/결제 수수료·환불·지원·번역/검수·모델/저장/커뮤니티 운영 원가를 포함한 유료 실증 후 정한다. 공헌이익=세금 제외 순매출−결제/환불−추론·저장·지원·콘텐츠/검수 변동비. MAU 규모만으로 지속 가능성을 판단하지 않는다.

북극성 지표 제안: **주간, 기록을 바탕으로 도움이 됐다고 확인한 돌봄 행동을 수행한 가정 수**. 사용자 회고에 의존하는 주관 지표이며 행동 개선/건강 효과의 인과 증거로 부르지 않는다. 함께 보는 지표는 첫 기록 완성률, D7/D28 가정 재사용, 질문 해결 체감, 상담 패킷 유용성, 오류·유해 안내·보류율, 삭제 성공, 유료 유지·환불, 건당 비용/지원 시간이다. 분모·관찰기간·모집 경로·국가/언어를 모두 남긴다.

## 냉정한 판단과 다음 결정
세계적 사용을 목표로 할 충분한 문제 크기와 반복 사용 시나리오는 있지만, 유사 기능 경쟁이 이미 존재하므로 기능 수만 늘려서는 선택 이유가 약하다. 성공 가능성을 만드는 핵심 증거는 ‘내 개를 더 잘 이해했다’는 반복 효용, 안전한 정확도, 가족/전문가와의 연결 가치, 지속 가능한 원가다. 고객 검증과 독립 평가가 아직 없으므로 세계1위 가능성이나 일정/매출을 확정할 근거는 없다.

다음 단계는 한국/영어권 보호자 인터뷰와 동일 과제 비교, 권한·개체가 확인된 평가자료, 맥락 기록→후속 행동→재방문 파일럿이다. 상세 우선순위·담당/의존성·통과 조건은 [개발 계획](03_ARCHITECTURE_AND_DELIVERY.md)에 고정한다.
