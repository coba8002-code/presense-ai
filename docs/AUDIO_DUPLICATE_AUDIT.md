# 확보 음원 중복 감사 · 2026-11-01

## 실제 결과

기존 캐시의 BarkMeowDB 개 음원46개와 ESC-10 원본400개를 사용했다. 신규 다운로드·외부 원본 전송·학습은 없다. 원본 SHA256를 기존 inventory와 대조한 뒤 임시 사본을 FFmpeg로16kHz 모노 PCM16 디코딩했다. 원본은 변경하지 않았다.

| 항목 | 결과 |
|---|---:|
| 실제 검사 파일 |446|
| BarkMeow 내부 비교 |1,035쌍|
| BarkMeow–ESC 비교 |18,400쌍|
| 원본 바이트 해시 동일 |0쌍|
| 디코딩·리샘플링된 전체 PCM 해시 동일 |0쌍|
| 유사 구간 후보 |41쌍, 전부 두 데이터셋 간|
| 후보에 포함된 BarkMeow 파일 |40개 /46개|
| 후보에 포함된 ESC 파일 |41개 /400개|

후보 구간의 절대 파형 상관 최솟값은 약0.9862다. 일부는 부동소수점 반올림 범위에서1이다. 이는 강한 검토 신호지만 개체 동일성·출처 소유권·전체 파일 동일성을 확정하지 않는다. ESC 쪽에는 dog뿐 아니라 rooster 라벨도 포함되어 **라벨 충돌 가능성**을 별도 검토해야 한다. 디렉터리 이름 dog만으로 정답을 확정하지 않는다.

**새로 확보한46개 파일을 독립적인 신규 개 음원46개로 계산하지 않는다.** 후보 연결 자료를 ESC 기반 학습 모델의 독립 보류평가셋으로 사용하지 않는다. 나머지6개도 독립성이 입증되거나 학습 승인이 된 것은 아니다. 이번에는 모든 파일/메타데이터의 기존 training_approved=false와 개체·가정 ID 미상을 유지했다. 삭제·병합·자동 라벨 변경은 하지 않았다.

## 방법과 한계

- 원본 해시, 동일 디코더/리샘플러의 전체 PCM 해시를 비교한다.
- 1초 구간을0.25초 간격으로 이동해512샘플 Hann FFT와16개 주파수 대역의 시간 변화 특징을 구한다.
- 대역별 평균을 제거하고 정규화한 특징 코사인>=0.97 후보 중, 파일쌍당 최대8개 강한 구간의 절대 파형 상관>=0.90인 경우만 검토 후보로 남긴다. 파일쌍별 가장 높은 파형 상관 구간을 기록한다.
- 무음·1초 미만 구간은 유사도 검색에서 제외한다. 전체 해시 비교에서는 제외하지 않는다. 타임스트레치·피치변경·혼합·재인코딩·임의 절단 위치·0.25초 격자 외 정렬을 놓칠 수 있다. 임곗값은 미검증 감사용 휴리스틱이며 중복 탐지 재현율을 주장하지 않는다.
- ESC의 src_file/source_url은 보관했다. BarkMeow에는 대응 원저작물 URL/개체/가정 정보가 없어 출판자 수준의 원본 출처 대조를 완결할 수 없다. 파일명 번호는 개체 ID가 아니다.
- 알려지지 않은 사전학습 코퍼스는 검사하지 않았다. 후보 없음은 데이터 독립성 증명이 아니다. 이번 결과로 기존 ESC 연구모델의 성능 수치를 수정하거나 실제 행동 정확도를 주장하지 않는다.

## 재현

```sh
OPENBLAS_NUM_THREADS=1 python -m evaluation.audio_duplicates \
  --barkmeow data/verified-expansion-20261101-v3 \
  --esc10 data/acquisition-20261028/esc10 \
  --output artifacts/audio-duplicates-new.json
python -m unittest tests.test_audio_duplicates
```

새 파일로만 출력한다. 완전한 캐시 inventory46/400개, 파일당 최대20MB·120초, FFmpeg WAV/file 전용 입력과20초 제한을 사용한다. 경로탈출/해시불일치를 거부한다. 전체 파일 해시 및 결과는 로컬 artifacts 보고서에 있으며, 공개 [감사 증거](evidence/AUDIO_DUPLICATES_20261101.json)는 입력 inventory 해시·도구 버전·41개 후보·전체 보고서 SHA를 포함한다. 원본 음원은 커밋하지 않는다.

회귀 검사는 동일 PCM/다른 원본표현, 음량변경·격자에 맞춘 부분 절단, 다른 소리, 무음, 실제44.1kHz→16kHz 디코딩, 원본 해시불일치를 포함한다. 합성 검사 통과는 실제자료 중복 판정의 정답 검증이 아니다.

다음은41쌍의 실제 청취·편집/원출처 조사와 라벨 충돌 검토다. 공유 원본이 확인되면 그 연결 전체를 같은 분할에 묶어야 한다. 현재 파일들은 자동으로 학습/평가에 편입하지 않는다.
