# 정답 확보 전략 — 전문가 전수 주석 없이 시작

## 권고
서비스에 전문가 시스템을 실시간 연동하거나 모든 영상의 라벨을 새 전문가가 작성할 필요는 없다. **관찰 가능한 항목의 독립 검수와 전문적 해석의 검증을 나눈다.** 기존 허가된 주석 데이터, 일반 검수자, 보호자의 사건 기록과 모델 보조를 조합하고 전문가는 기준·모호한 사례·표본 품질에 집중한다. 모델이 학습할 후보 라벨과 정확도를 판단할 최종 평가 정답은 별도다.

## 확보 경로
|경로|쓸 수 있는 근거|주요 한계/현재 상태|
|---|---|---|
|기존 주석 데이터|이미 부여된 소리 사건·관절 좌표·관찰 행동|작업 정의/권리/개체 ID/중복을 확인하고 원 주석의 품질을 점검해야 함|
|매뉴얼 기반 일반 검수자|앉기·눕기·서기·걷기·명확한 소리 사건|교육/이중 검수/불일치 관리가 필요하며 감정·원인 판단을 시키지 않음|
|보호자의 시점별 기록|초인종 직후·혼자 있던 시간·식사 전 등 보호자가 보고한 상황|자가 보고 사실과 해석을 구분. 초인종 직후 짖음이 공포를 증명하지 않음|
|VLM/음향 모델의 후보 라벨|사전 분류·사람이 볼 구간 선정·검수 우선순위|오류가 상관될 수 있음. 여러 모델의 일치도 독립 정답이 되지 않음|
|자기지도학습|허가된 무주석 영상/음성의 표현 학습|특징을 학습할 수 있지만 감정/행동 이름의 타당성을 증명하지 않음. 별도 실험 제안이며 새 파이프라인 구현 완료가 아님|
|출처 확인 전문가 자료/허가된 사례|관찰 기준·검색 기반 설명·전문 해석의 참고|기존 주석의 범위/원본 권리 확인. 방송 해설은 편집·선택·다중 요인 때문에 독립 정답으로 자동 전환하지 않음|

## 현재 자료에 적용할 범위
ESC-10은 개 소리 사건의 공개 기준 평가에 활용했다. 감정·의도·교정 성공 정답이 아니다. AP-10K의 개 관절 주석은 자세 모델의 근거이며 그 자체로 행동 원인이나 감정을 제공하지 않는다. AI-Hub59/71878은 사용자의 이용 승인 진술이 있지만 실제 라벨/개체/가정 스키마와 무결성 결과를 확인한 뒤 재사용할 항목을 정한다. 보행/건강 관련 명칭을 일반 행동·정서의 정답으로 바꾸지 않는다. DogSpeak/InterPet4D 등 별도 상업 조건이 미해결인 자료는 해결 전 사용하지 않는다.

## 권장 실행 방식
1. 먼저 자세 네 종류와 발성 사건 등 관찰 가능한 작은 라벨 집합으로 시작한다. 원인/감정/의학적 해석을 같은 정답 체계에 넣지 않는다.
2. 기존 주석의 작업 정의·출처·이용권한·개체 매핑을 검수한다. 모델/가정별 데이터 분할은 후보 생성 전에 고정한다.
3. 학습용 자료에는 모델 후보를 붙여 사람의 시간을 줄인다. 기존 training.video_review 흐름을 사용하되 후보를 검수 완료로 자동 승격하지 않는다.
4. 최종 평가용 자료는 모델 답/해설을 보여주지 않은 검수자가 독립 작성한다. 모호한 구간은 unknown으로 남기고 일부를 두 사람이 독립 검수한다. 기존 공개 정답은 벤치마크용으로 쓸 수 있으나 사전학습 중복과 알려지지 않은 개체 ID 한계를 명시한다.
5. 전문가는 새 전수 라벨 생산보다 기준 정의, 불일치/희귀 사례와 표본 점검에 투입한다. 초기 표본 비율은 실제 불일치율·위험도·예산을 보고 정하며 고정된 비율을 품질 보장으로 표현하지 않는다.
6. 실제 가정 외부 평가로 오류·유보·누락을 확인한 뒤 적은 데이터 전이학습을 비교한다. 모델 출력으로 만든 라벨로 동일 모델을 검증해 정확도를 주장하지 않는다.

## 전문가가 특히 유용한 부분
불안·공격 동기의 구분, 교정 권고의 적절성, 복합 행동과 위험 사례에는 행동 전문가의 검토가 유용하다. 전문가의 해석도 관찰 사실과 가설로 구분하고 불확실성을 기록한다. 수의학적 진단은 이 서비스 범위에 넣지 않으며 이상 징후에는 전문 상담을 안내한다. 전문가를 아직 확보하지 못했더라도 관찰·상황 기록·소리 사건 점수의 개발과 검증은 진행할 수 있다. 검증되지 않은 감정/원인 추론을 확정 기능으로 출시하지 않는다.

## 코드와 계획 반영
evaluation.video_contract의 HumanReview는 독립적인 사람 검수 계약이다. 전문가 자격이나 외부 시스템 실시간 연결을 요구하지 않는다. 기존 데이터 주석의 검수 근거를 재사용할 때 실제 원 검수자/시각/블라인드 여부를 모르면 값을 만들어 채우지 않는다. 해당 공개 벤치마크 전용 평가와 독립 현장 정답을 별도로 유지한다. NEXT_STEPS.md와 tasks/todo.md의 P0/P3도 이 역할 구분을 따른다.
