# G6 가족·돌봄자 읽기 전용 공유 — 2026-10-31

기존 글로벌 G6 설계와 계속 개발 지시에 따른 첫 기능 단위. 보호자는 선택한 개의 전체 보관 중인 상황·후속 일지를 1일 또는 7일 동안 한 계정에 공유한다. 수락 이후 새로 보관한 해당 개의 일지도 만료 전까지 포함된다. 소리 원본/분석 결과/독립 메모/다른 개체/회원 정보는 제외한다. 역할은 viewer 하나이며 수정·삭제·재공유 권한은 없다. 전문가 자격을 표시하거나 인증하지 않는다.

초대 코드는 256비트 난수, DB에는 SHA256만 저장한다. 원문은 생성 응답에서 한 번 표시하고 URL·웹 저장소에 넣지 않는다. 사용자가 직접 전달한다. 로그인한 수신자는 별도 동의 후 24시간 안에 한 번 수락한다. 동일 수신자의 재시도는 성공, 다른 계정의 재사용은 404, 본인 수락은 거절한다. 초대/공유 만료는 생성 시각부터 계산하고 개 프로필 기한을 넘지 않는다. 재발급 자동 재시도 없음. 계정당 100개/개당 20개/수신자당 100개 활성 상한.

소유자는 초대/공유 목록을 보고 즉시 철회한다. 수신자는 공유 종료로 자기 접근을 포기할 수 있다. 모든 조회는 현재 세션·권한·만료를 재검사한다. 보호자/수신자 탈퇴, 개 삭제·만료 시 권한도 삭제한다. 기록 삭제·만료는 다음 조회부터 반영한다. 이미 본/복사한 내용은 회수할 수 없음을 동의 문구에 명시한다.

API: /v1/me/care-shares GET/POST, /accept POST, /{id} DELETE, /{id}/journal GET(offset 50개), /{id}/journal/{case_id} GET. 수락 코드 본문은 4KB/15초 제한. POST 동의 care-sharing-v1, DELETE 확인 leave-or-revoke. 초대 발급·수락 모두 기존 cookie/CSRF/Origin 보호와 no-store 적용. SQLite v5→v6 보존 마이그레이션. 새 테이블 care_shares에 소유자/수신자/개체/만료/역할을 보관한다. DB 외부 감사 로그·메일·공개 링크·원문 복제는 추가하지 않는다.

작업: 실패 검사 → 스키마/권한/삭제·정리 → API → 한국어/영어 화면 → 테스트/검토 PR. 새로운 의존성 없음. unittest 및 기존 HTTPS 브라우저 검증 사용. `python -m unittest discover -s tests -p 'test_care_sharing.py' -v`; `python scripts/verify_release.py --output <new-file>`.
