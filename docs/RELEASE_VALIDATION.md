# 제한 베타 출시 검증 — 2026-10-31

작업 범위: ① 독립 행동 예측 채점 도구 ② 모바일 크기 Chromium 전체 계정/복구 흐름 ③ 제한 가입 정책과 안전한 실행 전 검사 ④ 국내 서버용 HTTPS·API·worker·만료 정리 배포 템플릿. 실제 서버/도메인·메일 발송 서비스·휴대폰·비공개 독립 정답은 현재 연결되지 않았다. 사용자가 배포 진행을 요청했지만 대상이 없으므로 실제 공개 배포를 성공으로 표시하지 않는다.

가입 정책은 개발 기본 open, 제한 베타 closed 또는 allowlist를 명시한다. 이메일 주소를 로그인 식별자로만 쓰는 현재 방식에서 allowlist는 이메일 소유 확인이 아니다. 복구는 일회용 오프라인 코드와 세션 철회를 유지하며 메일 복구 성공을 주장하지 않는다. 가입 실패는 명단 포함 여부를 공개하지 않는 일반 메시지를 쓴다.

배포 전 검사는 HTTPS 고정 origin/운영자·연락처·정책버전/제한 가입/계정 분석 모드/개발 외부 기능 비활성/현재 DB 스키마·POSIX 권한을 확인한다. 값을 로그에 내보내지 않는다. uvicorn은127.0.0.1:8000의 단일 프로세스, forwarded headers는127.0.0.1만 신뢰한다. Caddy가443/TLS를 담당한다. 검사 통과는 실제 TLS/DNS·원격 접근·백업/메일·물리 보안 검증을 대신하지 않는다.

휴대폰 검증은 mobile viewport/touch Chromium 에뮬레이션과 실제 Android/iPhone 시험을 구분한다. 마이크·코덱·배경 복귀·발열·실제 통신망 검사는 실기기가 필요하다.

독립 평가 도구는 고정된 자세 정답 계약과 정확히 일치하는 예측을 채점한다. 누락/오류는 유보, unknown은 알려진 자세 정확도에 넣지 않는다. 합성 예제는 도구 검증용이며 실제 성능이 아니다. 확률 보정/개체 신뢰구간/모델 추론은 별도 후속 검증이다.
