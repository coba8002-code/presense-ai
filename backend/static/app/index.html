작은 기록에서 시작하는 이해

오늘의 소리를 기록하고,
우리 개의 일상을 알아가세요.

소리 관찰과 보호자의 상황 기록을 함께 남깁니다.
감정과 행동의 원인은 아직 판단하지 않습니다.

우리 개 상황 살펴보기영상 장면 살펴보기소리 살펴보기 ↗내 기록 보기

01 / 관찰

궁금한 소리가 있나요?

직접 10초까지 녹음하거나 음성 파일을 선택하세요. 브라우저에서 16kHz WAV로 변환한 뒤 선택 구간만 분석합니다.

선택한 시작부터 최대 10초만 전송합니다. 원본 파일은 20MB 이하, 재생 가능 형식은 브라우저에 따라 다릅니다.

개발 서버 연결 설정

계정 세션은 아래 계정별 메모 영역에 입력합니다. 서버가 계정 모드면 개발 토큰은 사용할 수 없습니다.

토큰은 브라우저 저장소에 저장하지 않습니다.

서버 주소를 확인하세요. 로컬 PC에서 실행하면 그 PC에서 분석합니다. 원본 음성은 이 API에 저장되지 않습니다.

02 / 이해

관찰 결과

파일을 분석하면 소리 유형별 모델 점수가 나타납니다.

점수는 감정의 확률이 아닙니다. 확실하지 않은 판단은 보류합니다.

03 / 돌아보기

우리 개의 관찰 노트

저장한 이름·상황·분석 결과만 이 브라우저에 남습니다. 공용 PC에서는 사용 후 삭제하세요. 최대 100개까지 저장합니다.

04 / 내 메모 보관

계정별 보호자 메모

개발용 세션으로 연결합니다. 이름·상황 메모만 이 서버에 30일 보관하며 음성과 분석 결과는 전송하지 않습니다. 세션은 화면 메모리에만 남습니다.

반려견 프로필

계정당 최대 20개. 프로필은 기본30일 보관하며 상황 일지의 별도 동의로 선택한 기한까지 연장할 수 있습니다. 같은 이름도 따로 관리하며 기존 이름만 있는 기록을 자동으로 연결하지 않습니다.

선택 정보 · 견종·나이·체형

모름으로 두어도 이용할 수 있습니다. 보호자 입력이며 사진으로 견종을 판별하지 않습니다. 견종만으로 성격·감정·공격성을 판단하지 않습니다. 나이·체중은 입력 당시 값입니다.

분석용 개발 토큰과 별도의 세션입니다. 브라우저에 저장한 관찰 기록은 위의 삭제 기능으로 따로 관리합니다. 아래 목록은 최근 100개이며 다음 100개 버튼으로 이전 기록을 확인합니다.

05 / 분석 작업

계정별 소리 분석

위에서 녹음·파일을 고르고 계정 세션과 반려견 프로필을 선택하세요. 별도 작업으로 접수해 결과를 조회합니다. 서버에서 작업 기능을 켠 경우 사용할 수 있습니다.

소리는 완료·취소 시 먼저 삭제합니다. 같은 접수 번호는 중복 실행하지 않습니다. 동의를 해제하면 이후 등록을 막으며, 이미 접수한 작업은 목록에서 취소·삭제하세요. 브라우저 기록으로 자동 저장하지 않습니다.

선택 사항 · 분석 당시 상황

모르는 항목은 모름으로 두세요. 입력은 관찰 참고용이며 모델 점수·감정·원인 추론에는 반영하지 않습니다.

동의 해제는 새 전송을 중지합니다. 이미 접수됐거나 전송 중이던 작업은 목록을 조회해 취소·삭제하세요. 현재 프로필을 수정해도 이전 작업 당시 정보는 바뀌지 않습니다. 학습 자료로 자동 편입하지 않습니다.

06 / 모델 관찰 기록

같은 조건의 소리 점수 비교

완료된 서버 작업의 점수·모델 버전·출처만 별도 동의로 최대 30일 보관합니다. 원본 소리는 보관하지 않으며 프로필 만료가 빠르면 함께 삭제합니다. 작업 취소·결과 삭제는 연결 관찰과 피드백도 삭제합니다. 자동 학습·개체 확인·감정 판단을 하지 않습니다. 동의 해제는 신규 저장을 중지하며, 이미 저장한 자료는 삭제 버튼으로 지우세요. 전송 중 취소 시 저장 여부를 조회해 확인하세요.

07 / 학습 자료 준비

자료 수집·분석 상태

검색된 링크와 공식 피드의 제목만 표시합니다. 후보 발견은 영상 분석·전문가 검수·학습 완료를 뜻하지 않습니다. 외부 분석은 별도 이용권·설정·비용 승인이 필요합니다.

관찰 기록은 진단을 대신하지 않습니다. 급격한 이상이나 통증이 의심되면 수의사에게 상담하세요.
