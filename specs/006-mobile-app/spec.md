# Feature Specification: Android·iPhone 모바일 앱

**Created**: 2026-11-06
**Status**: Ready for implementation
**Input**: 안드로이드와 아이폰 앱을 Spec Kit으로 개발하고 현재 만들 수 있는 설치 파일부터 제공한다.

## User Scenarios & Testing

### User Story 1 — 연결 없이 우리 개 기록 (Priority: P1)

보호자는 앱을 설치하고 개 이름을 등록한 뒤 당시 상황과 이후 변화를 휴대폰에 기록한다.
**Why**: 서버나 모델이 준비되지 않아도 실제로 사용할 수 있어야 한다.
**Independent Test**: 네트워크 없이 프로필 등록→관찰/후속 기록→앱 재시작→조회→개별/전체 삭제.
**Acceptance Scenarios**:
1. 이름·상황·직접 관찰·보호자 생각·확인한 후속 결과를 구분해 명시적으로 저장한다.
2. 별도 저장 동의 없이는 보관하지 않고, 저장 후 다시 열어도 같은 기록이 보인다.
3. 개별 기록과 개 프로필을 삭제할 수 있고 프로필 삭제 시 연결 기록도 지운다.
4. 한국어와 영어를 선택할 수 있고 주요 작업을 두 언어로 완료한다.

### User Story 2 — 짧은 소리와 신중한 연결 (Priority: P2)

보호자는 개 소리를 최대10초 녹음하고 필요할 때만 자신이 설정한 서버에 분석을 요청한다.
**Why**: 기존 소리 분석 기능으로 연결하되 동의와 실제 준비 상태를 지켜야 한다.
**Independent Test**: 녹음 권한 거부/중단/취소, 동의 없는 전송0건, 준비 안 된 서버 표시, 모의 사건 점수 표시.
**Acceptance Scenarios**:
1. 녹음은 사용자가 시작하며 최대10초에서 멈추고, 취소·화면 이동·백그라운드에서 중단한다.
2. 원본 소리는 앱 저장소에 남기지 않는다. 전송 주소·반려견 소리 확인·별도 전송 동의를 확인한다.
3. 암호화 연결과 임시 인증 정보만 사용한다. 비밀을 앱 파일·기록·설정에 넣지 않는다.
4. 미연결·인증 실패·서버 미준비·시간초과를 알리고, 소리 점수를 감정/번역/진단으로 표현하지 않는다.
5. 요청 취소·동의 철회 뒤 도착한 결과는 화면에 적용하지 않는다.

### User Story 3 — 실제 설치 파일 (Priority: P3)

사용자는 안드로이드 설치 파일을 내려받는다. 아이폰 빌드가 불가능한 환경에서는 준비한 소스와 필요한 조건을 받는다.
**Why**: 문서만으로 완료 처리하지 않고 지금 가능한 설치 결과를 제공해야 한다.
**Independent Test**: 실제 APK 서명/패키지/권한 검사, 공통 앱 검사, Android 실행 가능한 기기/에뮬레이터 확인, iOS 프로젝트 확인.
**Acceptance Scenarios**:
1. 안드로이드 테스트 APK와 해시·설치 안내가 실제 파일로 존재한다.
2. 아이폰 프로젝트와 빌드 명령을 포함하며 Mac·서명 없이 설치용 IPA를 만들었다고 하지 않는다.
3. 기존 웹·서버·Windows 설치 파일과 기존 사용자 자료는 변경하지 않는다.

### Edge Cases

저장 실패·손상된 파일·프로필 상한20/기록 상한100, 30일 만료, 공백/긴 입력, 기기 시각,
마이크 거부·늦은 권한 응답·아주 짧은 녹음·앱 중단, 소리 표본 형식, 잘못된 주소/리다이렉트,
과대/잘못된 분석 결과·네트워크 중단·중복 전송, 작은 화면·큰 글씨, 도구/서명 부재.

## Requirements

- **FR-001**: Android/iPhone 공통 모바일 앱에 한국어·영어 화면과 개 전용 프로필 최대20개를 제공한다.
- **FR-002**: 보호자 관찰/가설/후속 결과를 구분하고 명시적 동의로 기기 내부에 최대100건·30일 보관한다.
- **FR-003**: 기록 개별/전체·프로필 연결 자료를 지우며 만료 자료를 불러오기와 저장 때 제외한다. 자동 외부 백업을 끈다.
- **FR-004**: 마이크 권한은 녹음 시작 때만 요청하고 10초·표본 상한·취소·백그라운드 중단을 적용한다. 소리는 메모리에만 둔다.
- **FR-005**: 사용자가 지정한 HTTPS 주소·개 소리 확인·별도 전송 동의·메모리 인증으로만 기존 사건 분석을 요청한다. 자동 재시도·리다이렉트를 하지 않는다.
- **FR-006**: 서버 점수는 관찰 가능한 소리 사건으로만 표시하고 보류/미준비를 유지한다. 분석 정확도·감정 번역·수의 진단을 주장하지 않는다.
- **FR-007**: Android APK와 소스 묶음을 만들고 서명·권한·해시·핵심 흐름 검사 결과를 기록한다.
- **FR-008**: iOS 프로젝트·권한 설명·개인정보 설정·재현 빌드 안내를 준비하고 실제 IPA/실기기 미검증을 구분한다.
- **FR-009**: 기존 서버/웹/운영 설정을 바꾸지 않고 모델 다운로드·학습·유료 호출·앱스토어 게시를 자동 실행하지 않는다.

### Key Entities

반려견 프로필, 보호자 상황 기록(직접 관찰/가설/후속 결과·관찰 시각·보관 기한), 언어/서버 주소 설정,
메모리 소리와 한 번의 분석 요청, 사건 점수/보류 상태.

## Success Criteria

- **SC-001**: 네트워크 없이 프로필·기록 저장과 재시작 조회·삭제 흐름을 완료한다.
- **SC-002**: 동의 전·취소/백그라운드 뒤의 소리 전송은0건이며 최대10초를 넘는 소리를 보관하지 않는다.
- **SC-003**: 한국어·영어 주요 화면에서 저장·조회·삭제·녹음·연결 상태를 이해할 수 있다.
- **SC-004**: 실제 안드로이드 설치 파일과 해시를 제공하고 아이폰 설치에 남은 조건을 정확히 알린다.

## Assumptions

첫 모바일 버전은 로컬 기록 중심의 개발 베타다. 기존 Windows 서버는 localhost만 수신하고 모델도 기본 비활성이므로
휴대폰 소리 분석에는 별도로 준비된 HTTPS 개발 서버가 필요하다. 연결 없이 기록을 사용할 수 있다.
모바일 회원 가입/계정 동기화·영상 분석·푸시·앱스토어 출시는 이 설치 베타 다음 작업이다.
현재 Windows에서 Android를 빌드한다. iOS는 공통 소스와 프로젝트를 준비하며 Mac/Xcode/서명 단계는 실제 환경이 필요하다.
기기 앱 삭제/OS 초기화 시 로컬 기록은 사라지며 다른 기기로 자동 복원하지 않는다.
