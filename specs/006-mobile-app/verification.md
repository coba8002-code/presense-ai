## 찾아 고친 오류

1. Windows C: Pub 캐시와 D: 프로젝트 사이에서 Kotlin 증분 캐시가 경로 충돌했다.
   프로젝트의 `kotlin.incremental=false`로 빌드 경계를 맞췄고 실제 APK 빌드가 통과했다.
2. Flutter 통합 테스트는 기본적으로 종료 시 앱을 삭제하여 이전에 부여한 마이크 권한도 사라졌다.
   재설치 뒤 테스트 앱에 권한을 부여해 네이티브 검사를 통과했다. README에 동일 테스트 APK 사전 설치와 `--no-uninstall` 절차를 적었다.
3. release 실제 UI에서 Home 뒤 빠른 복귀 시 paused 전에 돌아오면 준비된 녹음이 남았다.
   실패 회귀 검사를 먼저 만들고, 권한창 대기만 예외로 두어 inactive에서도 녹음/인증/요청을 지우도록 고쳤다.
   회귀 검사 통과 후 최종 APK를 다시 빌드하고 같은 실제 UI 동작이0.0초로 초기화되는 것을 확인했다.
4. 새 Flutter 프로젝트의 잠긴 `.gradle` 파일 때문에 기존 Windows 소스 패키지 검사가 실패했다.
   Windows builder에 Flutter 캐시·로컬 SDK 경로·서명 자료 제외만 추가했고 기존6개 검사가 통과했다.
   기존 Windows EXE/ZIP 자체는 다시 만들거나 바꾸지 않았다.
