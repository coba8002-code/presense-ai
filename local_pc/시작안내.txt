PetSense AI 국내 PC 실행 패키지 / 2026-10-28 KST

1. 먼저 할 일
압축을 푼 뒤 프로젝트 폴더에서 실행합니다. Python 3.12가 필요합니다.
Windows: local_pc/START_WINDOWS.cmd를 실행하면 pc-report.json이 생성됩니다.
Linux/WSL: python3.12 local_pc/pc.py doctor --output pc-report.json
보고서는 PC 이름·사용자명·키를 수집하지 않으며 자동 업로드하지 않습니다.
현재 제공자가 원격 PC에 접속하는 기능은 없습니다. 실제 실행은 해당 국내 PC에서 합니다.

2. AI-Hub 데이터 받기 (Windows는 WSL2 Ubuntu 24.04, Linux는 직접 실행)
Windows에서 WSL이 아직 없으면 Microsoft 공식 안내를 참고합니다:
https://learn.microsoft.com/windows/wsl/install
Ubuntu에서 필요한 기본 패키지:
sudo apt update
sudo apt install python3.12-venv ffmpeg curl unzip

공식 aihubshell 설치/지원 OS/API 키 발급 안내:
https://www.aihub.or.kr/devsport/apishell/list.do
공식 안내대로 설치한 aihubshell을 PATH에 추가합니다. 임의의 제3자 다운로드 도구는 필요 없습니다.
AI-Hub 승인 계정의 API 키는 다운로드할 때 PC 터미널에 숨김 입력하며 파일에 저장하지 않습니다.
공식 CLI는 키를 프로세스 인자로 받으므로 동일 PC의 프로세스 조회 권한자에게 노출될 수 있습니다.
개인 PC에서 실행하고 화면/로그를 공유하기 전 민감정보가 없는지 확인하세요.

파일 목록 확인 (인증 키가 필요한 경우 공식 안내의 실행 방식을 사용):
python3.12 local_pc/pc.py aihub --dataset 59 --destination data/aihub59
python3.12 local_pc/pc.py aihub --dataset 71878 --destination data/aihub71878

다운로드 (다음 숫자는 예시가 아닌 입력 자리입니다. 실제 파일 목록의 값을 넣어야 합니다):
python3.12 local_pc/pc.py aihub --dataset 59 --filekeys 실제파일키목록 --expected-gb 선택파일합계GB --destination data/aihub59
filekeys에는 숫자 또는 쉼표로 연결한 숫자만 넣습니다. 원천/라벨 쌍이 맞는 파일을 선택합니다.
예상 합계 크기의 3배 여유 공간을 검사한 뒤 공식 CLI를 호출합니다.
공식 CLI는 분할 파일을 병합·해제하고 압축을 제거할 수 있습니다. 공식 문서를 먼저 확인하세요.
데이터셋59는 개·고양이를 포함하므로 개 파일을 우선 선택하고 혼합 패키지는 로컬 검수 후 개만 추출합니다.
무조건 전체 다운로드하지 않도록 파일 키 입력을 필수로 했습니다.
네트워크 중단 시 공식 CLI 안내대로 재시도하고 영수증 파일은 다른 출력 폴더를 사용하세요.

다운로드 후 로컬 파일 목록과 해시 생성:
python3.12 local_pc/pc.py inventory --input data/aihub59 --output artifacts/aihub59-inventory.json
파일 해시는 변경 검출용이며 다운로드 원본의 진위를 단독으로 증명하지 않습니다.
원본 반출 조건/처리자 범위는 사용자가 승인받은 약관을 따릅니다.

3. 이미 확보된 데이터로 첫 음향 분석
별도 제공된 PetSense_esc10_20261028.zip을 프로젝트 폴더에 풀면 esc10/이 생깁니다.
PetSense_ap10k_dog_20261028.zip은 ap10k-dog/이 생깁니다.
이 실행 패키지에는 대용량 데이터 원본을 중복 수록하지 않았습니다.

CPU 분석 환경 설치 (Linux/WSL):
bash local_pc/setup_audio_cpu.sh

실제 ESC-10 400개 파일의 SHA256 검사 및 44.1kHz→16kHz 변환:
.venv-audio/bin/python local_pc/pc.py prepare-esc10 --input esc10 --output data/esc10-16k

개 소리/다른 소리가 섞인 10개 샘플 분석:
.venv-audio/bin/python local_pc/pc.py score-esc10 --input data/esc10-16k --output artifacts/ast-first --limit 10
전체400개 분석은 --limit 0. 먼저 10개 결과와 처리 시간을 확인하세요.
첫 실행에 고정 revision의 공개 AST 가중치를 인터넷에서 받습니다. CPU·RAM·다운로드 용량이 필요합니다.
입력 소리를 외부 추론 서비스로 전송하지 않습니다.
출력 폴더가 있으면 덮어쓰지 않습니다. 다시 실행할 때 새 이름을 사용하세요.
결과 파일: 샘플별 JSON과 summary.json. Dog/Bark/Howl 등 7개 사건 점수이며 감정·의도 판정은 아닙니다.
검증된 임계값이 없으므로 판단은 abstain이며 정확도는 null로 기록합니다.
이 단계는 사전학습 모델의 점수 확인입니다. 새 학습이나 운영 배포를 수행하지 않습니다.

4. 실제 학습에 넘어가기 위한 데이터 정리
AI-Hub59에서 실제 스키마를 먼저 확인하고 species=dog, 개체/가정/촬영세션 ID, 행동 라벨, 시간구간, 원본 출처를 매핑해야 합니다.
아직 파일을 열람하지 못해 스키마 변환기를 확정하지 않았습니다.
개체 ID를 파일명에서 임의로 만들지 마세요. 검수된 개체/가정 단위로 학습·검증·테스트를 나눕니다.
기존 docs/SMALL_VLM_TUNING.md, docs/PRETRAINED_DOG_AUDIO.md, docs/AUTOLEARN.md에 실험 경로가 있습니다.
ESC-10에는 개체 ID가 없어 기존 개체 분리 학습 registry에 자동 승인하지 않습니다.
AP-10K는 관절 데이터로 감정·교정법의 정답을 제공하지 않습니다. 3개 공식 split 대안은 서로 겹치므로 하나만 사용합니다.
GPU 결과를 확인한 뒤 LoRA 실험의 배치 크기/이미지 크기를 정해야 합니다.
현재 패키지는 GPU CUDA 설치나 유료 API 활성화를 자동으로 하지 않습니다.
